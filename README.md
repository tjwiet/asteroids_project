An "Asteroids" game made with the help of a Bootdotdev course. At completion of the course, the game allows for flying through space and shooting asteroids to destroy them. In the future, I plan on returning every so often to add updates to the game.



Set up virtual enviroment with:
  source .venv/bin/activate
deactivate with:
  deactivate

run with:
  uv run main.py

Controls:
 A: Turn left
 D: Turn Right
 W: Move forward
 S: Move backward
